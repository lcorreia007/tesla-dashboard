# Tesla Dashboard

A small web arcade for browsing and playing independent mini-games. The landing page currently features **Match 3**, with room to add more games as they are created.

## Run locally

```sh
npm install
npm run dev
```

Open the Vite URL shown in the terminal. The Match 3 game is available at `/games/match3.html`.

## Build

```sh
npm run build
npm run preview
```

Built with React and Vite. The Match 3 game is included as a standalone HTML game in `public/games/`.
